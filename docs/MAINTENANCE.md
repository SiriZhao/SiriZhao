# Profile maintenance

This repository is the public profile README for `SiriZhao`. Keep claims tied to public project source or documentation. The university and study background came from the owner; do not describe the computer science minor as admitted or completed without confirmation.

## Edit the page

- Update the introduction, project order, and toolkit directly in `README.md`.
- Keep CleanText Studio, Alpha Mosaic, and Meridian Alpha as the primary work. Their descriptions should track the linked project documentation and current readiness states.
- CleanText images are the actual `v2.1.0` interface screenshots copied from `CleanText-Studio/assets/screenshots/v2.1.0/`. Replace both light and dark copies together when the source release changes.
- Edit `scripts/make_project_art.py` and run `python scripts/make_project_art.py` to regenerate the two diagram pairs. The diagrams describe architecture; they do not represent returns or measured performance.
- The activity snapshot is made by `scripts/render_activity.py` from public GitHub repository metadata. The contribution trail is generated by `Platane/snk` using public contributions. Both are committed only when the output changes.

## Refresh activity

Open **Actions → Update profile activity → Run workflow**. The same workflow runs every Monday and Thursday. Check the run logs and `assets/generated/` if the images stop updating. The checked-in placeholders are intentionally honest until the first successful run. Leave the previous valid image in place when an API request fails.
